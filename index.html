Skema Presensi QR Code

Sistem ini dirancang untuk bekerja secara transparan dengan alur sebagai berikut:

  1. QR Code Harian: Admin menghasilkan QR Code dengan token terenkripsi unik setiap hari untuk mencegah kecurangan (misalnya screenshot QR lama).
  2. Waktu Scan Real-time: Saat guru memindai QR Code, waktu server/sistem dicatat.
  3. Kalkulasi Otomatis:
    • Waktu Scan ≤ Jam Masuk Guru + Toleransi → Tepat Waktu
    • Waktu Scan > Jam Masuk Guru + Toleransi → Terlambat
  4. Jadwal Piket: Guru yang terjadwal piket memiliki jam kedatangan default yang dapat disesuaikan pada tab Manajemen Guru untuk tugas pagi.
Perubahan aturan waktu akan langsung berdampak pada kalkulasi presensi baru berikutnya hari ini.
